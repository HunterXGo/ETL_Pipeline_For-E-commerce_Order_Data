# E-Commerce PowerBI Dashboard Guide

This guide provides step-by-step instructions for building a comprehensive PowerBI dashboard using the processed data generated by the ETL pipeline.

## 1. Import Data

Open PowerBI Desktop and import the following CSV files using **Get Data -> Text/CSV**:

**From `data/cleaned/`:**
*   `fact_transactions.csv` (This is your main Fact Table)

**From `data/dashboard_ready/`:**
*   `dim_customers.csv` (Customer Dimension)
*   `dim_products.csv` (Product Dimension)
*   `dim_date.csv` (Date Dimension)
*   `rfm_segments.csv` (Customer RFM Segmentation)
*   `customer_features.csv` (Additional customer metrics/features)

## 2. Setup Data Modeling (Relationships)

Go to the **Model View** (the relationship icon on the left) and create the following relationships by dragging and dropping the corresponding ID columns:

1.  `fact_transactions[CustomerID]` ➔ `dim_customers[CustomerID]` *(Many-to-One)*
2.  `fact_transactions[StockCode]` ➔ `dim_products[StockCode]` *(Many-to-One)*
3.  `fact_transactions[InvoiceDate]` ➔ `dim_date[Date]` *(Many-to-One)* 
    *(Note: Ensure InvoiceDate in fact_transactions is converted to a Date type first)*
4.  `dim_customers[CustomerID]` ➔ `rfm_segments[CustomerID]` *(One-to-One)*
5.  `dim_customers[CustomerID]` ➔ `customer_features[CustomerID]` *(One-to-One)*

## 3. Create DAX Measures

Go to the **Data View** or **Report View**, click on `fact_transactions`, and select **New Measure** to create the core KPIs:

**Total Revenue:**
```dax
Total Revenue = SUM(fact_transactions[TotalPrice])
```
*(Note: If TotalPrice doesn't exist, calculate it as `SUMX(fact_transactions, fact_transactions[Quantity] * fact_transactions[UnitPrice])`)*

**Total Orders:**
```dax
Total Orders = DISTINCTCOUNT(fact_transactions[InvoiceNo])
```

**Average Order Value (AOV):**
```dax
Average Order Value = [Total Revenue] / [Total Orders]
```

**Total Customers:**
```dax
Total Customers = DISTINCTCOUNT(fact_transactions[CustomerID])
```

**Average Quantity per Order:**
```dax
Avg Qty per Order = SUM(fact_transactions[Quantity]) / [Total Orders]
```

## 4. Dashboard Pages & Visualizations

Build the following 3 pages in your report:

### Page 1: Executive Overview
*   **Card Visuals (Top):** Total Revenue, Total Orders, Total Customers, Average Order Value.
*   **Line Chart (Revenue Trend):**
    *   X-Axis: `dim_date[YearMonth]` or `dim_date[Date]`
    *   Y-Axis: `[Total Revenue]`
*   **Map Visual (Sales by Geography):**
    *   Location: `dim_customers[Country]`
    *   Bubble Size: `[Total Revenue]`
*   **Donut Chart (Orders by Status - if available):**
    *   Legend: `fact_transactions[IsCancelled]` (True/False)
    *   Values: `[Total Orders]`

### Page 2: Customer Segmentation (RFM)
*   **Bar Chart (Customers by RFM Segment):**
    *   X-Axis: `rfm_segments[Segment]` (e.g., 'Champions', 'At Risk')
    *   Y-Axis: `[Total Customers]`
*   **Matrix / Table (RFM Summary):**
    *   Rows: `rfm_segments[Segment]`
    *   Values: `[Total Customers]`, `[Total Revenue]`, `[Average Order Value]`
*   **Scatter Plot (Recency vs. Monetary):**
    *   X-Axis: `customer_features[Recency]`
    *   Y-Axis: `customer_features[MonetaryValue]`
    *   Legend: `rfm_segments[Segment]`

### Page 3: Product Performance
*   **Bar Chart (Top 10 Products by Revenue):**
    *   Y-Axis: `dim_products[Description]`
    *   X-Axis: `[Total Revenue]`
    *   *(Apply a Top N filter = 10 based on Total Revenue)*
*   **Treemap (Revenue by Category - if applicable):**
    *   Category: `dim_products[Category]`
    *   Values: `[Total Revenue]`
*   **Table (Bottom Performing Products):**
    *   Columns: `dim_products[Description]`, `[Total Orders]`, `[Total Revenue]`
    *   *(Sort ascending by Total Revenue)*

## 5. Polish & Theme
*   Apply a consistent theme via **View > Themes**.
*   Add slicers on all pages for **Date Range** (`dim_date[Date]`) and **Country** (`dim_customers[Country]`).
*   Ensure all monetary DAX measures are formatted as **Currency**.
